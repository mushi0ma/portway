# Portway для Android

Клиент 0.2.0: Splash → подключение установки → регистрация/вход → главная с лимитами ИИ → новая задача для **Codex или Claude Code** на ноутбуке (выбор модели и уровня рассуждений) → ход выполнения и ответ → история с поиском/фильтрами → аккаунты ИИ (подключение ChatGPT/Claude через OAuth сервисов, переключение) → профиль и выход. Работает по реальному `/v1/codex/*` контракту ([Agent Bridge v2](../../docs/36-api-events-and-messages.md#agent-bridge-v2), OpenAPI 0.8.0), без заготовленных ответов в обычной сборке. Backend и мост на ноутбуке должны быть запущены: [операции](../../docs/52-build-deploy-and-operations.md#codex-demo-operations). Дизайн-система и отличия от Figma — [DESIGN.md](../../DESIGN.md).

## Сборка и проверка

Из этой папки, Flutter **3.47.2**, Dart **3.13.2**, JDK 17+, Android SDK (target 36):

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

Готовый кандидат: [`output/android/portway-demo-0.2.0-3.apk`](../../output/android/portway-demo-0.2.0-3.apk) (debug, не подписанный release; Android 7+, target 36). `pubspec.lock` закрепляет зависимости; добавлены `url_launcher` (открытие страниц входа во внешнем браузере), `flutter_markdown_plus` + `markdown` (ответ модели). Русская локализация генерируется из `lib/l10n/app_ru.arb`.

**Демо-сборка без сервера** (только для скриншотов/показа интерфейса): `flutter build apk --debug --dart-define=PORTWAY_FIXTURES=true`. Она использует in-memory хранилище и встроенные фикстуры (`lib/dev/`), на каждом экране видна лента «ДЕМО». Обычная сборка эти фикстуры не включает (compile-time флаг) и никогда не показывает выдуманные ответы.

## Структура

- `core`: HTTP envelope и ошибки с `details`, HTTPS validation, session/refresh coordinator, защищённое хранилище, токены (`colors.dart`), ThemeData, форматирование времени.
- `features`: `auth_screen` (подключение, регистрация, подтверждение email, вход), `home_screen`, `compose_screen`, `run_screen`, `tasks_screen`, `accounts_screen`, `profile_screen`, `brand` (знак), `bridge_models` (провайдеры, аккаунты, модели, лимиты, вход), `codex` (repository, композер с идемпотентной отправкой, контроллер запуска).
- `dev`: фикстуры демо-сборки и тестов.
- `test`: протокол (HTTP fixtures новых маршрутов, разбор лимитов/исчерпания, машина состояний входа), widget-тесты (достижимость экранов, валидация, баннер лимита, 200 % текста, rail), golden Dark/Light.

## Поведение и безопасность

- Сессия и незавершённая отправка — в secure storage; cleartext и backup отключены; prompt, ответ, коды входа и токены не пишутся в лог. Тема (Системная/Светлая/Тёмная) сохраняется.
- Отправка задачи повторяет тот же `Idempotency-Key` при неопределённом исходе и не создаёт новую задачу автоматически. Состояние моста, лимиты и вход читаются из `GET /v1/codex/status` (≈2 с во время входа/команды, реже в покое); при открытии и возврате приложения запрашивается `POST /v1/codex/usage/refresh`.
- Вход в аккаунт ИИ: «На этом телефоне» — код устройства ChatGPT (крупно, с копированием, страница `auth.openai.com`) или ссылка claude.com и поле для кода Claude; «На компьютере» — браузер открывается на ноутбуке. Ссылки открываются только https и из allowlist сервера. Код Claude передаётся один раз и не сохраняется в приложении.
- Не реализованы в клиенте: SSE обычных runs, апрувы/reviewer, FCM, редактор агентов, ZIP/SAF.

## Показ на эмуляторе

На ноутбуке установлен AVD **Portway_Demo_API36** (`system-images/android-36/google_apis/x86_64`). Повторный показ из корня репозитория:

```sh
python3 scripts/demo-android.py --check
python3 scripts/demo-android.py
```

Скрипт поднимает существующий Docker Compose без пересборки, мост (Codex + Claude Code с текущими входами CLI), AVD и устанавливает APK с сохранением данных приложения. Он не регистрирует владельца и не отправляет запросы модели. Для уже работающих API/моста — `--skip-stack`.

Сценарий защиты (КМ07): Splash → «Зарегистрироваться» (показать проверку пустых/неверных полей) → вход (показать ошибку неверного пароля, затем верный вход) → Главная (статус компьютера, лимиты) → нижняя навигация → Профиль и назад → «Новая задача»: Claude Code или Codex, модель, запрос, например «Кратко объясни назначение проекта Portway по README. Ничего не изменяй» → ответ → «Задачи»: поиск и фильтр → «Аккаунты ИИ» → Профиль → «Выйти». Регистрация нового владельца требует значение `PORTWAY_SETUP_TOKEN` из `.env` и подтверждение email; не показывайте код на презентации.

Эмулятор не заменяет физический телефон, TalkBack, FCM и полный MVP. Фактические результаты: [протокол 0.2.0](../../docs/evidence/flutter-redesign-2026-10-13.md), предыдущий кандидат 0.1.0 — [протокол](../../docs/evidence/flutter-client-2026-10-13.md).
