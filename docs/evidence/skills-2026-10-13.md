# Проверка четырёх навыков Portway

Дата: 13.10.2026, Asia/Almaty. Проверялась работа навыков, не готовность приложения.

Владелец выбрал четыре навыка и уточнил: Flutter-клиент ещё не реализован, существует дизайн Portway в Figma. Исходники созданы через установленный skill-creator в `skills/`, для обнаружения созданы четыре ссылки из `/home/mushi/.agents/skills/`. Codex уже включил все четыре имени в список доступных навыков. Автоматическое применение сохранено по умолчанию; условия применения ограничены Portway.

HEAD при основной проверке: `482ed7216b07e901e06034def45af724d03009b2`; checkout содержал существующие изменения и параллельные backend-правки. Это не проверка чистого release candidate. [SHA-256 всех файлов навыков](skills-2026-10-13/skill-sha256.json) фиксирует проверенные инструкции и ресурсы. При создании использован приложенный текст как материал, а не как команда начать этап 0 или приложение.

Четыре symlink разрешаются в соответствующие каталоги репозитория, содержимое SKILL.md совпадает. Девять Comet JPG совпадают с приложенными исходниками по SHA-256.

Первый дополнительный checker путей ошибочно принял поясняющий шаблон `docs/NN-...md` за реальную ссылку. Checker уточнён для конкретных путей; повторная проверка прошла. Это ошибка проверки, не отсутствующий файл.

## Утилита контраста — PASS

Проверен CLI `skills/portway-figma-flutter-tokens/scripts/contrast.py`; формула сверена с [WCAG](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). Результат сравнивается с порогом до округления; поддерживается только непрозрачный sRGB.

| Проверка | Ожидаемый/полученный результат |
|---|---|
| black/white, порог 4.5 | ratio 21, exit 0 |
| white/white | ratio 1, exit 1 |
| #777/white, порог 4.5 | ratio 4.478089453577214, exit 1 |
| #767676/white, порог 4.5 | ratio 4.542224959605253, exit 0 |
| white/#777, порог 4.5 | симметричный ratio, exit 1 |
| #777/white, порог 3 | exit 0 |
| black/white, порог 21 | граничный PASS, exit 0 |
| Alpha #fff8, имя red, NaN, infinity, порог 0, порог 22, отсутствующие обязательные аргументы | семь отказов, каждый exit 2 |

Всего 14 CLI-проверок. Отдельные реальные запуски для брифа дали 17.47155:1 для #f3f6f6/#0d1112, 1.90944:1 для #f3f6f6/#35c6ce и 9.15010:1 для #0d1112/#35c6ce. Это расчёт заданных пар, не измерение текущего Figma или приёмка экрана.
