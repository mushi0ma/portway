## Приоритетный native Codex demo, 13.10.2026

Реализован отдельный `/v1/codex/*`: protected status/admission/history/detail, cursor polling и stop; SQL 009 хранит encrypted prompt/events/result, текущую device authority и одноразовые lease. Native `portway codex-bridge` использует установленный CLI 0.159.3 и существующий ChatGPT login, фиксированный operator workspace `portway`, read-only sandbox, очищенное окружение и cancellation process group. API/provider keys не нужны для этого пути. Каждый запрос — независимый ephemeral сеанс, не существующий Desktop chat.

## Ближайшая работа

Единая очередь — [implementation plan](implementation-plan.md): **IP-01/IP-02a/IP-02b локально проверены → IP-02c verified tokenizer → IP-03 Runtime → IP-04 публичный run**. Реальный accepted model/capabilities ещё требуются. Android/FCM, reviewer, перенос и итоговая приёмка остаются обязательными. Срезы и условия готовности больше не дублируются отдельным списком здесь.

Рабочий foundation-стек развёрнут с реальной Supabase и доступен по HTTPS через Tailscale Funnel; owner signup/email ещё не проверен. Локальная PostgreSQL используется только для тестов, согласно ТЗ. `/readyz` остаётся 503 до появления готового исполнения; `/v1/status` показывает отдельно готовность конфигурационных операций.
