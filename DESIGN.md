# Дизайн Portway

Источник: Figma `BZ7UxNzlF3OmJRhd5JS19s` (локальная копия `docs/portway(1).fig`: 18 семейств экранов UI-01…UI-18, коллекции `Portway — Foundations/Dark/Light`). Макет — исходный набросок; клиент 0.2.0 реализует его структуру и тон с правками UI/UX (14.10.2026).

## Принципы
Режим Operate: смысл → состояние → причина → следующее действие. Одно основное действие на экран; плоские поверхности без вложенных карточек; статус всегда передаётся цветом, иконкой и текстом. Material 3 рисует системные панели, клавиатуру и диалоги — их не копируем из макета. Работают только реальные функции: экраны агентов-редактора, апрувов, пакетов и хуков из Figma в клиент не перенесены, пока их нет в API.

## Иконки и бренд
Одно семейство — Material Symbols rounded/outlined из Flutter SDK; размеры 18–24 dp (20 в строках и карточках, 24 в навигации), один цвет роли. Крупные пиктограммы и эмодзи-статусы макета заменены. Знак Portway — плитка accent с «P», чья ножка заканчивается точкой порта (`lib/features/brand.dart`), та же геометрия в adaptive launcher icon и Android splash (`android/app/src/main/res/drawable*`).

## Что изменено относительно Figma
- **Навигация:** вместо разнородных меню — нижняя панель на 4 раздела (Главная · Задачи · Аккаунты ИИ · Профиль), rail на широком экране.
- **Главная (UI-05):** вместо карточки апрува — статус компьютера, карточка активного ИИ-аккаунта с полосками лимитов (5 часов / неделя) и заметный баннер «Лимит исчерпан» со временем сброса (абсолютным и «через N ч M мин») и действиями «Сменить аккаунт» / «Перейти на другой провайдер».
- **Новая задача (UI-09):** вместо длинной формы с версиями агента — чат-композер: переключатель Codex / Claude Code, выбор модели и уровня рассуждений, строка ввода внизу, кнопка отправки; отправка блокируется с объяснением (компьютер не в сети, нет аккаунта, лимит исчерпан).
- **Задача и результат (UI-10/13):** пузырь запроса, сворачиваемая лента хода выполнения, ответ в Markdown с блоками кода и копированием, метаданные (провайдер, модель, аккаунт, токены).
- **Подключения (UI-08) → Аккаунты ИИ:** вместо ввода endpoint/ключа — OAuth самих сервисов через CLI на компьютере: код устройства ChatGPT крупно с копированием, вставка кода Claude, вариант «на компьютере», активный аккаунт и лимиты каждого.
- **Профиль (UI-17):** владелец, установка, сессии устройств с отзывом, тема (Системная/Светлая/Тёмная, сохраняется), версия, выход с подтверждением.
- Вложенные карточки, конкурирующие основные кнопки, мелкие (11 px) метаданные и псевдо-системные панели макета убраны.
